🔍 LibreChat Multi-Banner Debug Tool

Herramienta de diagnóstico para problemas con banners múltiples

🛠️ Acciones Rápidas

📝 Instrucciones

  1. Limpiar Banners Dismissed: Elimina todos los banners que hayas descartado
  2. Ver localStorage: Muestra qué banners has dismissed
  3. Verificar API: Comprueba cuántos banners devuelve el backend
  4. Diagnóstico Completo: Ejecuta todas las comprobaciones

Nota: Esta herramienta debe abrirse en la misma pestaña donde está LibreChat (mismo dominio) o usar las DevTools del navegador.
